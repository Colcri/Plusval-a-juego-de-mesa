# 🎲 Plusvalía, juego de mesa — Co-creación Comunitaria

¡Bienvenido/a al repositorio oficial de **Plusvalía, juego de mesa**! Este es un proyecto de innovación social y comunitaria enfocado en el desarrollo de un juego de mesa diseñado por y para la ciudadanía de **Otra República**. 

Este espacio ha sido creado para centralizar el desarrollo del reglamento, las mecánicas y los componentes del juego de forma abierta, transparente y participativa.

---

## 🚀 Sobre el Proyecto
Este juego de mesa busca enseñar a los trabajadores a tomar acciones colectivas.

El juego se encuentra actualmente en **fase de desarrollo (Prototipo/Borrador)**.

---

## ⚖️ Blindaje Legal y Licencia Comunitaria

Este proyecto se rige bajo los principios de la **Cultura Libre y el Código Abierto**. Para garantizar que el juego siga siendo un bien común y proteger el esfuerzo colectivo frente a posibles apropiaciones indebidas, se han establecido los siguientes mecanismos de protección:

1. **Prueba de Prioridad (DNDA):** La estructura base, mecánicas originales y textos contenidos en este repositorio se encuentran bajo constancia de registro de autoría previa ante la **Dirección Nacional de Derecho de Autor (DNDA)** de la República de Colombia.
2. **Huella de Tiempo Inmutable:** El historial de *commits* de este repositorio de GitHub actúa como evidencia técnica pública de la fecha, hora y autoría de cada aporte y modificación.

### 📄 Licencia de Producción de Pares (PPL)
Toda la documentación, reglas y archivos de este juego se distribuyen bajo la **Licencia de Producción de Pares (Peer Production License)**. 

*   **Uso Libre y Colaborativo:** Se permite y fomenta la copia, modificación, distribución y uso de este material por parte de comunidades autogestionadas, colectivos sociales, cooperativas y trabajadores organizados sin ánimo de lucro.
*   **Prohibición de Apropiación Privada:** Queda **estrictamente prohibida** la apropiación individual, el registro privado, el patentamiento de mecánicas o la explotación comercial de este juego por parte de personas naturales, empresas o entidades con fines de lucro capitalista.
*   **Efecto CompartirIgual (Copyleft):** Cualquier obra derivada, expansión o finalización de estas reglas debe publicarse obligatoriamente bajo esta misma Licencia PPL, reconociendo siempre las co-autorías colectivas.
*   **Destino de las Ganancias:** Las futuras ganancias derivadas de la producción física de este juego serán administradas colectivamente y reinvertidas exclusivamente en proyectos de bienestar para la comunidad de **Otra República**.
